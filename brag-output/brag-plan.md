# Brag Plan: UTGPT

## What is this app?
UTGPT is an offline, on-device AI chat application built specifically for Ubuntu Touch that runs lightweight Large Language Models (LLMs) like Qwen2.5, SmolLM2, and TinyLlama directly on mobile hardware.

## The angle
AI in your pocket without the cloud. While mainstream mobile AI relies on cloud servers and telemetry, UTGPT runs quantized GGUF models locally on Ubuntu Touch with complete privacy, hardware-level tuning, and zero internet connection required.

## Hook (first 2-3 seconds)
Text slam: "Who said your phone needs the cloud for AI?"
Subtext: "Run Large Language Models natively on Ubuntu Touch."

## Key moments (the middle)
- Model Catalog: Seamless switching between lightweight GGUF models (Qwen2.5, SmolLM2, TinyLlama).
- Hardware Tuning: Mobile performance controls for CPU threads, context size, and Flash Attention.
- Real-Time Inference: Fast token streaming, animated thinking indicator, and markdown formatting running entirely offline.

## Outro / punchline
"Zero servers. Zero telemetry. Pure on-device intelligence."
UTGPT logo reveal and Ubuntu Touch badge.

## User flow worth showing
1. Model Selection: User chooses a local GGUF model from the catalog.
2. Hardware Optimization: Adjusting CPU thread allocations and Flash Attention for mobile silicon.
3. Chat & Streaming: Prompt submitted, dynamic thinking indicator pulses, and tokens stream live onto the screen.
